# クレジット

## 音声

音声合成: [VOICEVOX](https://voicevox.hiroshiba.jp/)

本作で使用している VOICEVOX 話者:

- `VOICEVOX:波音リツ`
- `VOICEVOX:WhiteCUL`
- `VOICEVOX:後鬼`
- `VOICEVOX:小夜/SAYO`
- `VOICEVOX:栗田まろん`
- `VOICEVOX:†聖騎士 紅桜†`
- `VOICEVOX:ユーレイちゃん(CV:神崎零)`

話者の選定と利用規約の確認は `docs/voicevox-licensing.md`。ユーレイちゃんの音声は非商用利用の許諾範囲で使用しています。本作を商用利用する場合は、各権利者の規約に従い事前許諾を取得してください。

効果音: `~/.omp/agent/skills/game-production/scripts/audio_gen.py` による手続き生成（第三者の音源素材を含まない）。
